# Capturas de tela

Coloque aqui as imagens usadas no README principal. Tire as capturas do site
publicado (ou de `npm run dev`) na **demonstração** (`/demo`), que usa dados
fictícios — assim nenhuma informação pessoal aparece nas imagens.

| Arquivo | O que mostrar | Tamanho sugerido |
| --- | --- | --- |
| `pagina-inicial.png` | Página inicial pública (`/`) | 1440 × 900 |
| `inicio.png` | Painel da demonstração (`/demo`) | 1440 × 900 |
| `estatisticas.png` | Estatísticas, aba Semana | 1440 × 900 |
| `cronometro-celular.png` | Cronômetro rodando no celular | 390 × 844 |
| `biblioteca.png` (opcional) | Biblioteca com filtros | 1440 × 900 |
| `historico.png` (opcional) | Histórico com uma observação aberta | 1440 × 900 |
| `livro-ja-lido.png` (opcional) | Formulário "Adicionar livro já concluído" | 1440 × 900 |
| `login.png` (opcional) | Tela de entrar (`/login`) | 1440 × 900 |

Dica: no Chrome, abra as Ferramentas do desenvolvedor, ative o modo de
dispositivo (Ctrl+Shift+M), escolha a largura e use "Capture screenshot".
